# Скриншоты CV Screener

Кадры работающего React-интерфейса с реальным локальным бэкендом. Для съёмки создан отдельный запуск с 223 резюме, содержащими явную пометку synthetic, отдельной историей из пяти демонстрационных подборов и избранным кандидатом. Реальные документы и рабочая история в этот запуск не подключены.

Подбор, сравнение, отчёт, диалог и проверка источника показаны на демонстрационных резюме Morgan Reed, Dana Brooks и Riley Stone. Ответы взяты из сохранённых запросов к OpenAI; для съёмки новые запросы не выполнялись. В копиях ответов оставлены только используемые демонстрационные источники и согласованы номера ссылок; формулировки рекомендаций и цитат сохранены.

Контакты и личное резюме владельца проекта в кадры не включены. Исходные документы и файлы истории не входят в этот каталог.

PNG сохранены без потерь, без дорисовки интерфейса и без увеличения готового изображения. Размеры заданы в браузере до съёмки; использован шрифт приложения. Снята видимая область экрана, поэтому длинные страницы продолжаются ниже границы кадра.

Для сайта используйте оригиналы с `width: 100%; height: auto`. Основной кадр — `01-candidates.png`; для подробного показа функций подойдут `02-comparison.png`, `03-report.png` и `04-source.png`. Предусмотрите открытие полного изображения по нажатию. Мобильный кадр рассчитан на отображение шириной до 430 CSS-пикселей. Избегайте дополнительного сжатия в JPEG: оно ухудшает мелкий текст.
